# 校园网助手 1.5.8

早晨的定时任务现在最多等 30 秒取得宿舍 Wi-Fi，受原时段截止时间约束。如果任务在等待 Wi-Fi 时结束且尚未发出网络请求，会登记一次时段外补登。普通时段内的原有备用任务仍可先行恢复。

补登适用于当天开始、在北京时间中午 12 点前结束的早晨计划。时段结束后，系统可在当前或随后连接的 Wi-Fi 上调度一次检查，App 核对网关和网段，并在指定 Wi-Fi 上判断是否需要认证。已经联网时直接结束。遇到其他 Wi-Fi 保留机会。确认匹配后持久记录机会已使用，避免重复通知或进程中断引发再次提交。用户可在首页停止，关闭计划或更改配置会取消等待。

后台采用网络可用通知与受 Wi-Fi 条件约束的系统任务。截止时刻同时在任务启动和执行时检查，清理用闹钟无需唤醒设备。系统调度可能晚于 Wi-Fi 实际连接时刻。尚待 Redmi K80 Pro 真机隔夜验证。

针对 11 月 4 日日志中的未取得 Wi-Fi 场景，回归覆盖 20 秒后 Wi-Fi 才就绪、07:05 后在指定网络认证一次、已在线零提交、错误网关、中午到期、停止计划和重新绑定。

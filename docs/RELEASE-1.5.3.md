# 1.5.3 胶囊导航与横向切页

- Dock 恢复完整胶囊形状，外轮廓与阴影半径为高度的一半，选中底块也恢复胶囊。卡片保留 24dp 圆角；统一曲线与视觉风格，不再强行统一圆角数值。
- 检测间隔使用主题底部选择卡片，当前值以主题底色、边线和勾选图标标记。点选自动保存，取消不改变。导入配置已有的其他间隔继续保留。
- 主题图标重新绘制为带调色点与缺口的调色板，去掉圆形笑脸图案，保留与指南的顶部对齐和统一笔画。
- 点击导航切换首页、设置、记录时按目标方向横向滑动；新页面进入、旧页面退出，Dock 固定且选中底块同步移动。取消旧动画与完成回调，快速切换可打断并从当前位置继续；关闭动画时直接切换。修复隐藏页面首次没有测量宽度导致动画跳过的问题。

81 项 Android 模拟测试通过（API35 为 80 项，API26 为 1 项）。新增检查底部间隔选择、导入值保留、取消、自动保存，以及横向位移、快速切换和关闭动画后的可见性。明暗布局另作渲染检查。原签名覆盖安装，版本 1.5.3 / 10503；未进行本版真机动效、120Hz 或隔夜验证。后台认证与自动保存机制保持原有逻辑。

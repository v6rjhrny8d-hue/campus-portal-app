# 校园网助手 1.5.5

本次优化针对 2026-10-30 的诊断日志：定时事件晚到约 46 秒，启动后两次外网验证又等待约 32 秒。

## 改进

- 已绑定 Wi-Fi 的回调显示存在认证页、尚未验证联网时，优先发现当前认证页，不再先等待百度和腾讯的 HTTPS 检测。仍须读取可信认证页、检查协议后才能提交账号。
- 状态不明确时，登录前 HTTPS 预检采用 4 秒共享预算，每个地址最多分配 2 秒；登录后及手动网页验证采用 10 秒共享预算，每个地址最多分配 5 秒。
- 单个请求的连接、响应头和正文读取共用请求预算；每阶段按剩余时间缩短超时，增加到期断开和迟到结果检查，避免连接与读取各等一轮完整超时。底层 DNS、TLS 或 disconnect 的可中断性仍取决于 Android 网络实现，预算不等同于任何情况下都严格按时返回。
- HTTPS 联网验证维持默认 TLS 证书校验，只读取响应头，不下载首页正文；认证页面和接口仍读取所需正文。所有请求继续绑定宿舍 Wi-Fi。
- 同一运行任务中，认证接口已经接受但 HTTPS 暂未验证时，后续轮次仅复查联网，避免反复提交账号。
- 增加请求阶段耗时、预算、闹钟方式、权限、单调时钟延迟与墙钟偏移日志，区分系统调度迟到与校时影响。计时信息缺失或设备重启时明确标为不可对照。

## 更新安装

直接覆盖安装 1.5.5，包名与签名沿用 1.5.4，versionCode 从 10504 提高至 10505。账号、绑定网络、时间设置与主题沿用原有数据。安装后打开一次，确认自动计划与下次执行时间。

## 验证与限制

- 纯 Java 核心回归：268 项断言通过。新增认证优先路径、慢外网预算、认证标记滞后、仅读响应头、连接/读取共享时间、超时断开和迟到结果检查。
- Robolectric：84 项测试通过，包括 Android 15 生命周期和网络流程、Android 8 界面兼容性。新增同一任务认证成功后不重复 POST 和闹钟双时钟诊断验证。网络与账号为测试夹具；测试专用 JVM Keystore 提供者不代表设备安全验证，也不进入 APK。
- APK 构建和 v2/v3 签名验证通过；证书与 1.5.4 一致。
- 未执行 Redmi K80 Pro / Android 16 的实机、校园网和隔夜定时测试，不承诺实测 1～5 秒完成。
- 当前源码原已使用 setExactAndAllowWhileIdle。46 秒闹钟迟到的根因未由旧日志证明，本次保留调度方式并增强诊断，不能宣称已修复这部分延迟。

安装后可先点“仅检测”，联网状态正常时应不提交账号；需要认证时再验证登录。下一次早晨任务完成后，可导出 1.5.5 日志对照调度延迟与任务运行耗时。

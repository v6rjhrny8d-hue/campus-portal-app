# 1.3.4：后台自测增加检测并登录

## 使用
覆盖安装，保留旧账号及配置。设置 → 后台联网自测 → 延迟检测与结果 → 安排两分钟后自测 → 检测并登录（使用已保存账号）。随后熄屏等待，约三至四分钟后查看“延迟登录自测”结果，也可导出记录。

仅检测模式保留，不发送账号。检测并登录模式使用原有 TaskRunner / PortalClient 认证流程，读取本机加密保存的凭据；已在线则停止，不重复登录。未认证时探测当前受信任认证页、提交认证并验证实际 Wi-Fi HTTPS 访问。不开启网页脚本自动填密码，不改变证书校验。

一次测试最多九十秒，无每日循环；原有网络完全无响应时最多重新申请一次 Wi-Fi 的机制仍在。认证被拒绝时保留十五分钟冷却。不会自动注销现有校园网会话，需要测试重新认证时由用户自行退出校园网登录。

自测成功不标记每日计划已完成；停止自测不停止当天自动计划；不修改每日开始/结束时间。两种延迟模式共用一个待测名额，重新安排会替换之前的待测。取消待测可取消任一模式。

登录测试要求本机账号可读取。安排后若配置或账号版本发生变化、账号不可读、已有其他任务，或延迟超过五分钟，则跳过，需重新安排。结果分别保留前台对照、仅检测、检测并登录三组，显示状态详情、请求/响应/提交次数、耗时及环境，不记录密码。

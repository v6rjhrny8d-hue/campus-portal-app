# 1.4.0 译读风格界面重构

以校园网助手 1.3.6 为基线，参考 TransRead 0.5.48 的 `APP_PALETTES`、主导航和卡片动效，使用原生 Android Views 实现校园网助手的交互；未引入阅读器功能和 WebView 主界面。

## 变化

- 默认鼠尾草绿，提供雾樱粉、雾霾蓝、烟熏茶棕、石墨紫和月岩灰；每套支持跟随系统、浅色、深色。主题、触感偏好保存在单独的 `campus_ui` 设置中，不改原账号和定时配置。选择主题时内存保存当前表单草稿，包括正在输入但未保存的内容，再重建界面。
- 底部首页、设置、记录使用悬浮胶囊，可点击或水平拖动选中项。按压、胶囊切换、卡片进入与关闭提供可打断的轻柔动效。页面切换保留任务状态、网络结果和计划的独立表达。
- 弹窗、指南、夜间检查和时间选择统一为底部卡片；把手支持下拉收起，指南滚动到顶部后可继续下拉收起。滚轮仍支持 24 小时、跨午夜、取消和有效时段校验。
- 六套颜色、明暗模式与关闭／轻柔／标准触感可在主题与交互中选择。触感遵循系统设置，时间滚轮可单独关闭；减少系统动画时不强制播放动画。
- 悬浮导航在 Android 12+ 且硬件加速时对可见页面的小尺寸内存快照进行模糊；卡片使用系统窗口背景模糊。系统关闭或不支持时退回半透明底色，不截取或保存屏幕文件。实际效果及帧率需真机验证。
- 未修改任务执行、定时、认证、网络会话、恢复调度、配置和自测核心文件。继续维持 Wi-Fi 实际网页访问验证与任务成功后结束的行为。

## 验证与边界

- 247 项 JVM 核心断言。
- Android 15 / API 35 模拟测试覆盖后台生命周期、认证、Wi-Fi 恢复、主题对比度、导航拖动、表单草稿保留、滚轮、指南和卡片交互。
- Android 8 / API 26 模拟兼容性检查覆盖界面、滚轮和主题卡片的构造；模拟测试不能代替实际系统验证。
- 使用 Robolectric 对暗色首页、设置、时间滚轮、主题卡片进行静态布局检查；无法证明 GPU 模糊、120 Hz 帧率或厂商系统表现。
- 包名、签名与旧版相同；应在用户手机上覆盖安装并核对账号及计划。尚未在 Redmi K80 Pro / Android 16 上实测本版界面、耗电或隔夜任务。
- 此源码基于会话中可取得的 1.3.6 版本，未取得可能只存在于用户电脑上的后续本地源码。

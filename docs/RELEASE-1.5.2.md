# 1.5.2 圆角与顶部图标对齐

Dock、主卡片和弹出面板统一采用 24dp 外圆角。Dock 阴影轮廓与背景使用同一圆角，选中底块按 6dp 内缩采用 18dp 圆角，避免内外曲线不协调。

顶部栏左右内边距统一为 16dp，指南和主题均使用 48dp 触摸区域及 24dp 图标框；两个图标使用相同的 18 单位圆形外轮廓、中心与 1.8 单位线宽。主题图标重绘内部调色板符号。

79 项 Android 模拟测试（API35 78 项，API26 1 项）通过，明暗布局渲染已检查。沿用原签名，自动保存、认证与后台任务逻辑不变。版本 1.5.2 / 10502。未进行本版真机或隔夜测试。

# 1.5.0 简化设置与卡片交互

基于 1.4.2，落实用户提供截图中的设置、记录、白色残留、遮罩过渡和底部系统区域反馈。

## 设置

移除主页的指定网址卡片、登录网址字段、JSON 高级配置和保存高级配置入口；保留配置导入／导出、清除本机账号和离线指南。以前保存的指定网址在下一次可用自动保存时清空，认证继续使用既有自动探测。内部协议适配与服务器配置结构保留，兼容既有配置。

移除保存设置和保存并测试按钮以及保存栏。文本和选项停止更改约 900ms 后尝试自动保存，失焦静默保存，切换页面和应用暂停时立即尝试。时间面板确认后更新表单并自动保存，取消／下拉关闭不提交时间草稿。指南已同步说明。

完整账号密码才替换旧账号；只输入新账号、密码或清空原账号时保留原账号，不提交半成品。单独修改有效网络／计划配置仍可保存。自动保存不重建表单、不清空正在输入的密码；密码继续由原有 Keystore 机制加密，不增加明文持久化副本。重复保存相同配置与凭据不会增加配置修订、重复加密、日志或重新安排计划。仅凭配置保存不自动发起认证，登录测试保留首页入口。

执行任务时维持原来的禁止改动配置规则，修改先保留在内存草稿，任务结束且界面可用时再保存。若此时关闭并被系统清理，尚未提交的草稿不视为已保存。自动保存失败显示错误并等待新输入或明确操作，不随每次界面快照无限重试。

## 记录与页面

记录页默认每条收起，显示时间与一行摘要，支持全部展开、全部收起和单条操作，最多呈现快照中的最近 200 条；不再按主要／详细事件过滤。完整日志仍可导出。三个主页的顶部标题、英文副标题及记录介绍移除。

主窗口延伸到手势导航条区域，取消导航栏对比度遮罩与分隔线；系统手势横条本身保留。Dock 通过系统底部安全距离避开手势区，滚动内容延伸到下方，键盘可用区域单独处理。

## 卡片与遮罩

时间选择原先给内部内容和外层 ScrollView 都绘制了白底，只移动内部内容，外层背景留在原位。现在只有外层 ScrollView 绘制实色背景，整张视图一起移动。

卡片统一使用一个动画控制平移和窗口变暗值，进入前等待首次布局，不再分别做透明度和内容动画；关闭、反向打断及拖动回弹从当前位置继续。切换卡片时接替前一窗口并关闭旧窗口，防止两个变暗层重叠。

统一由对话框分发手势，移除把手和指南各自重复的拖动实现。卡片内非冲突区域可下滑收起；内容已向上滚动时先滚回顶部，横向移动锁定横向交互。小时／分钟滚轮、NumberPicker、SeekBar、横向滚动、输入、下拉选择、开关和文本选择不触发收起；多指操作终止卡片拖动，取消或未越过阈值时回弹。拖动接管时向原控件发送取消事件，避免松手后误点。

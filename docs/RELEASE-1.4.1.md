# 1.4.1 界面修正

以已交付的 1.4.0 为基线，针对用户提供的四张截图修正卡片、指南、设置底部和时间选择。

## 变化

- 卡片、指南、主题面板、时间选择、普通弹窗及导航均使用不透明实色背景；移除窗口背景模糊、导航背景截图及 RenderEffect 绘制。首页状态卡也使用单一实色。
- 默认雾霾蓝（原始主题色 #4A6985，按钮按文字对比度适当调整），首次运行、缺少主题设置或无效主题时均回落蓝色；已明确保存的其他主题保留。应用资源的启动背景和系统强调色同步改蓝。
- 指南采用统一无衬线字体，外层卡片裁切圆角，内容在单一视口内滚动，关闭滚动条、边缘渐隐和过度滚动效果，避免滚动条压住卡片。
- 设置页不再绘制保存栏背景；内容视口、保存按钮和底部导航各占独立空间，没有叠在输入内容上的遮罩层。键盘弹出时隐藏导航并让出下方空间。首页和记录页也不在导航后绘制内容。
- 重做时间选择：自绘 24 小时双列滚轮，五行数字、单条选中底色和冒号，去掉原生分隔线与重复的选中字层。支持拖动、惯性、吸附、点击邻近数字、键盘方向键和辅助功能滚动／设置数值。惯性仅在可见轮盘交互期间运行，脱离窗口取消。
- 开始／结束分段显示完整时刻；切换分段保留草稿并停止旧轮盘惯性。确认和主题应用增加一次性处理，防止退出动画期间重复点击。取消、下拉关闭和返回不保存时间草稿；非法时段不能确认。确认时段之后仍需保存设置。
- 长内容和大字体时，时间面板高度限制在可用高度内，整体可以滚动到操作按钮。

## 验证

通过 247 项 JVM 核心断言、68 项 Android 15 / API 35 模拟测试和 1 项 Android 8 / API 26 模拟测试（共 69 项）。详见 RELEASE-CHECKS-1.4.1.json。核心断言覆盖认证、调度和取消边界；Android 模拟覆盖生命周期、Wi-Fi、网络、界面及 Android 8 兼容。新增检查涵盖轮盘触摸循环、辅助调整、跨午夜、取消、重复确认、默认蓝色、背景不透明、指南裁切与滚动条、保存与导航布局，以及 320dp 宽／1.6 倍字体时能滚动到确认。

使用 Robolectric 原生绘图渲染明暗主题的首页、设置、指南首尾、主题选择和时间面板并人工检查。绘图检查只代表指定窗口状态；没有把它等同于真机触摸或流畅度测量。

逐字节比对 1.4.0：TaskRunner、WorkService、ScheduleManager、ScheduleReceiver、RecoveryScheduler、RecoveryJobService、WifiSession、NetworkController、Config、BackgroundTest、PortalClient、PortalProtocol、BoundHttpTransport、RunControl、Schedule 共 15 个核心文件完全相同。

包名 org.campusportal.app，版本 1.4.1 / 10401，minSdk 26，targetSdk 35；沿用原签名。没有改账号加密密钥或计划存储。

未在 Redmi K80 Pro / Android 16 真机上测本版安装、触摸和隔夜任务；用户此前确认的夜间省电根因与既有成功结果保持不变。本版不宣称新的省电百分比。

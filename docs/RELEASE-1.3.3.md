# 1.3.3 更新与验证

本版针对前台检测成功、早晨后台所有请求无响应的问题改进。尚未证实真机根因，也未完成 Redmi K80 Pro / Android 16 的锁屏或隔夜验证。

## 改动
- 设置 → 配置与高级设置 → 后台联网自测：立即检测建立前台对照；“延迟检测与结果”中安排两分钟后检测，随后可退到后台或锁屏。回来查看两组时间、环境、请求/响应/提交次数及耗时，也可以导出连接记录。
- 自测使用相同的 TaskRunner、Wi-Fi 会话及 PortalClient 检测流程，但只检测、不提交账号。自测不标记每日计划已完成、不关闭自动计划；停止自测不停止当天自动时段。与已有任务冲突时跳过；过期超过五分钟不执行。自测可取消；系统可能延迟触发，日志记录实际延迟。
- 整轮请求无响应且未提交账号时，自动前台任务与自测各最多重新申请一次 Wi-Fi 会话；剩余时间不足三十秒时不追加。旧连接关闭后才继续；失败仍使用已有系统备用任务，严格保留原时间窗口。
- 网络日志补充轻度休眠、低功耗待机开关与豁免、主界面是否前台及进程重要性。请求区分创建连接、连接（DNS/TCP/HTTPS握手合并阶段）、写入认证、等待响应头、读取响应体。不声称能单独测出 TLS 握手耗时，不记录原始异常消息或密码参数。
- 首页及记录区分无响应和认证失败，避免所有请求均无响应时误导为无法解析登录页面。
- 保留先验证实际 Wi-Fi 网页访问、已在线即结束的路径；不以系统 validated 标志直接代替验证。不更改蜂窝或 VPN 设置。

## 建议的真机验证
1. 覆盖安装，不卸载旧版，保留账号和配置。
2. 保持宿舍 Wi-Fi，做一次“立即检测”，等任务结束。
3. 安排“两分钟后检测”，先退回桌面测试一次；再安排一次并锁屏，检测结束后回来查看结果。
4. 若短时检测均成功，仍需验证整夜待机，以及工作日需重新认证时的自动登录。检测自测不会主动提交账号，不能代替真实自动认证验证。
5. 若锁屏仍失败，导出日志以对比请求阶段和电源状态；本版不把任何假设直接认定为根因。

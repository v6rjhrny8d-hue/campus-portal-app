## Android 原生检查

Android 10（API 29）临时模拟器上直接安装本次同一 APK：

- **1.1.1 → 1.2.0 覆盖安装 6 项检查通过**：加密账号、加密密码、网络绑定与备注、时段/间隔/星期、自动计划开关、已完成时段标记。
- **33 项原生检查通过**：默认值、48 dp 主操作、自适应图标、首次准备状态、固定保存按钮、未绑定时阻止保存并测试、持续错误提示与输入保留、Keystore 往返与私有存储、状态刷新保留草稿、历史成功与待机状态、认证拒绝、45 秒间隔回显、实际 Wi-Fi 网络选择与绑定网络的本地 HTTP 请求、定时规划/取消、开机接收器恢复计划、前台服务启动/取消、日志脱敏、权限范围和返回退出。
- Wi-Fi HTTP 请求只访问模拟器宿主机的虚构测试响应，不提交学校账号；开机接收器检查是代码调用，不代表真实手机重启验收。
- 初轮测试的虚构绑定缺少网关/网段，导致配置校验失败；测试失败截图又因尚未创建界面而崩溃。修正测试数据并保护截图后，上述覆盖安装和原生检查全部通过。未因这一测试问题修改正式 APK。

## 真实手机验收范围

以下项目需要用户手机及学校网络，本版未将它们记为通过：

- 保持移动数据开启，在实际宿舍 Wi-Fi 上完成认证与 HTTPS 联网验证。
- VPN 关闭，以及 VPN 开启并排除 org.campusportal.app 两种状态。
- 锁屏进入设定时段、成功后退出前台服务、次日再次唤醒和真实手机重启后恢复计划。
- 厂商自启动、电池限制、系统强制 VPN 与通知设置。
- 实际耗电测量；本版不报告未经测量的省电百分比。

更新时直接覆盖安装，不要先卸载或清除应用数据。模拟器的覆盖安装检查只能验证测试设备上的保存机制，不能替代每台手机的验收。

# 校园网助手 1.5.7

## 弹窗按钮与长结果

- 修复后台联网自测、延迟后台自测三个按钮等分横排导致的文案换行、胶囊高度不齐。共用YiduSheets组件改为三个操作全宽纵排，主操作优先，关闭/取消低强调；两个操作按实际文字宽度、字体缩放、内边距与间距判断是否可等高横排，否则纵排。
- 按钮至少48dp高，不通过缩小字号或省略关键文案塞入窄列。正文和操作区分开，使用实际测量代替字符数估算高度，长结果可滚动到最后一项。
- “查看详细自测记录”采用统一按钮工厂，移除默认平台StateListAnimator、elevation、translationZ，补足滚动区下缘空间，避免阴影裁切。
- 自测操作缩短为“延迟自测”“两分钟后自测”；修复快速连点重复关闭弹窗，单次操作只派发一次。

## 夜间休眠省电重点提醒

- 夜间运行检查卡新增醒目提示“重要：可能需要关闭夜间休眠省电”，自测说明与使用指南同步提示。
- 明确电池优化显示“已豁免”不代表厂商夜间省电开关已关闭。若手动登录正常、隔夜定时失败，建议检查并尝试关闭该开关。

- 应用不读取或代关厂商私有开关，不虚报已就绪；保留后台自启动、熄屏自测和隔夜确认说明。

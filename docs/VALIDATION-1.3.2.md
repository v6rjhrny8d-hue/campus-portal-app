## 新增覆盖

- 核心测试：已在线时普通和保存链接模式均先验证 HTTPS，跳过认证页与 POST；未认证时保留发现、校验、编码、账号冷却及认证后验证。
- 调度测试：idle 闹钟进入带 Wi-Fi/NOT_VPN 条件、无需 VALIDATED 的加急任务；网络失败结束前台服务并去重接续；系统任务固定使用分配网络，重新分配时停止旧任务。
- 网络回调测试：等待完整就绪状态；VALIDATED 不能覆盖 blocked；允许尚未验证的认证 Wi-Fi；丢失、更换网络或 IP 变化后拒绝旧连接；拒绝 VPN、移动网络、错误网关和空的任务网络；释放回调并忽略迟到事件；错误原因保留 errno 但不泄露消息内容。
- 完整模拟：真实任务状态机在已联网时只有一次 HTTPS 请求并标记时段完成；全失败且零提交时进入恢复任务，然后在新的系统分配网络验证成功、结束原时段。
- 1.3.1 的停止、系统超时、拒绝提升、重复启动、旧任务收尾、时段截止、取消代次、配置变化、退避和用户停止测试继续通过。

模拟网络不访问真实学校服务器，不使用用户凭据。Robolectric API 35 不是 Android 16 或 HyperOS 的网络策略实现。

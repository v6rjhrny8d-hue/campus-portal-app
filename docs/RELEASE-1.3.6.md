# 1.3.6 用户体验更新

基线为本工作区可获得的 1.3.5 源码；未取得也未覆盖可能仅存在于用户电脑上的后续本地修改。发布版本为 10306 / 1.3.6，包名和签名与原版一致。

## 变化

- 设置时间使用原生 24 小时、时分双列滚轮；切换开始和结束时间时保留草稿，确认后填回表单，再由设置页的保存操作生效。支持跨午夜，单次最多两小时；开始和结束相同或超过上限时显示错误。顶部把手下拉可取消，滚动数字不会触发该手势。触感开关只影响滚轮并遵循系统触感设置。
- 首次设置卡片保留，新增离线指南、分步跳转、夜间运行检查和自测入口。电池优化豁免与厂商夜间/自启动设置分开表述，不声称豁免就是隔夜成功。
- 后台自测在原有入口下展示简明结果并保留详细记录；保留原有测试方式和计划行为。记录页展示最近状态与主要事件，详细记录仍可展开和导出。
- 全新配置默认 07:00—07:05；已保存的设置通过原配置字段读取，不被此默认值覆盖。
- APP 界面在前台但任务未运行时，刷新间隔从 3 秒变为 15 秒；任务运行时保持 3 秒，进入后台仍停止界面刷新。尚未进行耗电测量，不将此变更表述为已测量的后台节电。
- 继续使用 1.3.5 的认证、调度、重试、资源释放和日志记录代码。根据用户的本机测试，旧版早晨失败与夜间休眠省电有关，调整设置后当天已成功；本版未重新测定该设备的实际策略。

# 1.5.1 精简入口与交互设置

- 移除设置页「主题与交互」卡片及配置与数据下方的使用指南。右上角统一打开主题面板，左上角指南保留；首页指南入口不变。
- 移除时间滚轮单独的触感开关，忽略旧 wheelHaptics 偏好；按钮和滚轮均由主题面板的关闭／轻柔／标准控制，并遵循系统触感设置。
- 主题面板新增「开启动画」开关，默认开启；选择在点击应用后保存，取消不改变。关闭后按压、导航、页面、卡片进出和滚轮惯性／吸附动画直接完成；系统禁用动画时本应用也不强制播放。
- 右上角主题图标重绘为带四个色点的连续调色板轮廓。
- 连接记录始终完整展开，删除全部展开／收起以及单条折叠操作，文本可选择和复制；仍显示最近 200 条，完整日志可导出。

验证：79 项 Android 模拟测试（API35 78 项、API26 1 项）通过，覆盖记录完整显示、移除入口和动画开关确认／取消。明暗布局渲染检查另行执行。没有进行本版真机动效或隔夜验证。认证、自动保存、定时与账号加密逻辑不改，沿用原签名覆盖安装。版本 1.5.1 / 10501。

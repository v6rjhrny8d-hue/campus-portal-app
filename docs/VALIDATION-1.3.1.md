# 1.3.1 验证记录

日期：2026-10-24（北京时间）。

## 核心验证

230 项 JVM 断言通过：保留 1.3.0 的 192 项协议、编码、可信主机、保存链接、网页探测、只读检测、拒绝冷却、配置及调度检查，新增 38 项后台可靠性回归断言。

新增场景包括：启动前收到系统超时后不建立连接；系统超时原因不被用户/销毁回调覆盖；只允许特定系统失败启动备用任务；时钟向前/向后调整时保持截止；临近结束缩短请求超时；提交前再次检查截止；停止主动断开阻塞响应；迟到的 HTTP 成功不可算作联网成功；取消中断不误记为 DNS 或学校故障；过期、禁用、成功、停止、窗口变化不允许备用认证；首页中断与排队状态。

## Android 生命周期模拟

Robolectric 4.16、Android API 35、JDK 17，执行实际应用类，模拟平台服务与时钟。15 个测试通过：

- 启动即超时停止前台服务、释放唤醒锁，安排只使用 Wi-Fi 的备用任务。
- 超时先于启动回调时，不再启动工作线程。
- 重复启动保留原截止时间，停止覆盖最新 startId。
- 进入前台被拒绝时不启动网络线程，转交系统备用任务。
- 旧任务的迟到收尾不释放新任务。
- 独立截止检查可以结束未返回的工作线程所属任务。
- 取消代次、配置修订号和过期窗口各自拒绝旧备用任务。
- 加急额度不足时申请普通任务。
- 系统停止备用任务时取消工作，不错误调用 jobFinished。
- 失败后安排原间隔重试，旧 stop 回调不停止新代次。
- 成功窗口不再续排。
- 用户停止后已送达的旧任务不可复活。
- 系统用户停止不请求重调度。

Robolectric 不是完整 Android 模拟器，也没有执行厂商后台策略、真实 JobScheduler 配额、真实网络和页面 UI 渲染。注入超时回调只验证 APP 响应，不说明系统为什么触发该回调。

## 发布检查

SDK Platform 35 / Build Tools 35.0.0 编译成功。APK 完整性、版本、包名及 v2/v3 签名通过；证书 SHA-256 与 1.3.0 实际 APK 一致。具体 SHA-256 和检查结果写入 `RELEASE-CHECKS-1.3.1.json`。

正式包无 Robolectric/JUnit 测试依赖。源码包不包含签名密钥、密码、SDK、APK、构建缓存或用户诊断日志。账号密钥别名与已有配置字段不改，新增运行状态字段使用独立键；这是源码兼容性检查，不替代手机覆盖安装验收。

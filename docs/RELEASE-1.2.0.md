# 1.2.0：把设置、运行与最近结果分开

## 本次行为变化

- 首次使用显示三步准备：绑定网络、保存账号、测试连接。已配置且有成功验证记录后，收起这张引导卡。
- 首页分别显示最近联网结果、最近检测时间、当前任务和自动计划。过去的成功明确显示为“上次联网验证成功”，说明未持续监测。
- 账号拒绝、等待 Wi-Fi、网页尚未验证和其他失败提供对应的处理入口。
- 设置页保留“保存设置”，新增“保存并测试”。未绑定网络时，保存并测试会先阻止操作并保留输入，避免部分写入。
- 错误显示为可收起的持续提示；缺少账号或密码时，在字段旁提示，不清空其他输入。
- 增加“快速填写 07:00—07:05”，填写后仍需保存。不会在安装时自动改变已有时段。
- 明确成功后结束、再次掉线等待下次计划或手动登录的行为。
- 窄屏或大字体下动作按钮纵向排列；大字体输入框提高高度。
- 通知准备状态读取系统真实通知开关；已授权时可进入本应用通知设置。

## 保留的实现与兼容性

沿用 org.campusportal.app、同一签名、相同 SharedPreferences 名称与 Keystore 别名。没有更改账号加密格式、认证协议、Wi-Fi 通信、定时计算或 1.1.1 的成功提前结束逻辑。

覆盖安装 1.1.0／1.1.1，应保留账号、绑定网络、服务、时间、间隔与开关。不要先卸载或清除数据。包名不变，因此 VPN 中对校园网助手的排除项仍指向同一应用；更新后应检查运行准备和下次计划。

## 设计依据与取舍

设计决策参考 APP 设计参考库中的任务架构、渐进设置、真实状态与错误恢复章节。保留现有原生 Java Views 和主题，减少为视觉改版引入的依赖。

本次是对已有 APP 的定向实现，不是完整可用性审计。视觉检查以本版实际 Android 渲染为依据；源码检查、模拟器检查和真实校园网验收分别记录。没有测量耗电量，不声称具体省电百分比。
